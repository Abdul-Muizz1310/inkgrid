# M5c-2 Tables and Furniture on Public Corpora Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the table and furniture errors spec 11 § 5 left reported (missed thin rules, grids
reaching past their table, frames read as grids, charts read as tables, a watermark in cells,
table text taken as furniture), each test-first, then run the benchmark again labelled as tuned.

**Architecture:** The reader keeps thin fills as rules and reports filled shapes and diagonal
words; the Camelot reader finds a frame's core. The table stage splits accepted grids at the
page's own rules, rejects a grid overlapping an accepted one, uses a frame's core, and refuses a
chart; the corridor stage ends a piece at a drawn rule, keeps foreign words out, and refuses a
chart. Furniture takes the page's grids. A pure `core/tables/chart.py` holds the chart evidence.

**Tech Stack:** Python 3.12+, uv, pytest 9, Hypothesis, Ruff, mypy `--strict`; PyMuPDF 1.28.2,
Camelot 2.0.0.

**Spec:** `docs/specs/14-tables-and-furniture.md`

## Global Constraints

- Never loosen a check to make a document pass: every rule here changes the reading, not the
  verifier.
- Every word stays owned exactly once: a rule that stops a table claiming words leaves them to prose.
- The 42 fee schedules read as before, bar changes each explained (the M5c gate against
  `~/.cache/inkgrid-bench/m5c/fixpass/fee`, one document at a time, niced).
- Every `OPENABLE` fixture verifies with no defect; the layer table holds (only
  `read/camelot_reader.py` imports camelot; `core` imports only `model`).
- ASCII-only source (every new test file through an escape pass); Conventional Commits, no trailer.

## Review Focus

1. **A real table refused**: a chart rule, an overlap, or a frame core firing on a real fee table
   (shaded rows, tiers beside sub-row rules, a spanning header with a row-spanning label column).
   CH3, FR3, GO2 pin the known shapes; the fee gate must show no table lost.
2. **Words lost or doubled when a table shrinks**: words a refused grid or a trimmed frame no longer
   claims must reach prose once (the partition proof, and the OPENABLE fixtures verify clean).
3. **A split at a rule the page does not draw visibly**: splits only after acceptance (LS4), and only
   where the verifier would report a rule dividing a cell.
4. **Furniture lost**: S1 or S2 un-marking a real running header or footer (FT3, FT4, and the fee
   gate's 1,237 furniture lines).
5. **Rotated pages**: grids and fills turned into the view frame for every new rule; the core and
   chart boxes in the same frame as the words they test.
