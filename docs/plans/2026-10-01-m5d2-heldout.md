# M5d-2 Held-out Fee Set and Glyph-verified Sample Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Score every tool on 31 pages of 11 fee schedules no fix has seen, against ground truth the
user verified table by table, plus cell CER on 200 glyph-verified cells.

**Architecture:** Pure code in `heldout.py` (selection, the ground truth's model, access paths, the
glyph sample, cell CER) and `draft.py` (words in a drafted grid, review images); the ground truth is
data under `bench/heldout/`; `run.py --datasets heldout` reads only those documents and refuses to run
if inkgrid's reading has changed since the tuned run. The user's review happens in a private review
page whose answers Claude reads back.

**Tech Stack:** Python 3.12, uv, pytest 9, Hypothesis, mypy `--strict`; PyMuPDF, pypdfium2, Pillow.

**Spec:** `docs/specs/16-held-out-fee-set.md`

## Global Constraints

- No benchmarked tool reads a held-out document before the ground truth is verified (spec 16 § 3).
- `src/inkgrid` is not changed in M5d-2; the held-out run checks it against `7f70dd6`.
- No held-out number from an unverified file; the PDFs are never committed.
- ASCII-only source; Conventional Commits, a subject of at most 72 characters, no trailer.

## Review Focus

1. **Ground truth that silently favours one tool**: text taken from a reading a tool shares, header
   flags set from a tool's output, or pages chosen by how a tool reads them.
2. **Scores over pages that are not scored**: a tool's tables on unscored pages counted, or a scored
   page's absent tables not counted as misses.
3. **A wrong frame**: ground-truth boxes on a turned page, or a tool's, compared in different frames.
4. **CER that rewards structure errors or punishes none**: the closest-cell rule picking across tables
   or pages it should not.
5. **Claims beyond the intervals**: eleven documents give wide intervals; README must say so.
