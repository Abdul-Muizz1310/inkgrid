# M1 (Text) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `inkgrid.read()` turns a `Reading` into a valid `Document`: furniture, lines, column-aware
reading order, prose blocks, and assembly with the partition proof, plus Markdown, `inkgrid read`,
and the HTML inspector.

**Architecture:** Configuration values live in `model/config.py`. The pipeline is pure functions in
`core/` over frozen dataclasses of the core's own (`Line`, `Region`, `ProtoBlock`,
`FoundFurniture`), and it ends in one `Document` construction that runs every invariant. `api.read`
is the only place the shell meets the core. The inspector lives in `render/`, which may call `read/`
for page images.

**Tech Stack:** Python 3.12+, pydantic v2, PyMuPDF 1.28 (page renders only), pytest 9, Hypothesis.

**Spec:** `docs/specs/04-text-pipeline.md` and `docs/specs/05-read-and-inspector.md`, with the model
additions in `docs/specs/01-model.md` (invariant 8d, D46). Parent: `docs/specs/00-design.md`.

## Global Constraints

- `core/` imports only `inkgrid.model`, `inkgrid.errors`, and the stdlib (`tests/test_architecture.py`).
- `render/` imports only `inkgrid.model`, `inkgrid.read`, and the stdlib; only `read/pymupdf_reader.py`
  imports pymupdf.
- Every source file is ASCII: non-ASCII test data is written as `\uXXXX` escapes (`test_sources_are_ascii`).
- Tests are named `test_<CaseId>_<slug>`, with the spec's case ids.
- Every `src/` file keeps 80% branch coverage (`scripts/check_coverage_floors.py`).
- Ruff (`extend-select`), `ruff format`, and `mypy --strict` stay clean; no `# type: ignore` without a code.
- Fixtures are generated in `tests/support/pdf_factory.py`, never committed as PDFs.
- Commits: Conventional Commits, imperative, subject at most 72 characters, no emoji, no
  `Co-Authored-By` trailer.
- The text rule is exactly two transforms (whitespace to one space, recorded hyphen joins); nothing
  else rewrites text.

## Review Focus

1. A page whose only words are furniture: it contributes no content blocks and the `Document` is
   valid (PL5, Task 7).
2. A doubled text layer (two words with the same text and box): both words are kept, in one line
   (LN9, Task 3).
3. A dense page (1500 lines): the section walk must stay fast (LY11, Task 5).
4. A body-size line opening with a superscript word: a paragraph, not a footnote, and its marker is
   recorded (PB14, Task 6; markers checked by invariant 8d).
5. Two blocks with the same text on one page: twin keys, still a valid `Document` (AS10, Task 7).
